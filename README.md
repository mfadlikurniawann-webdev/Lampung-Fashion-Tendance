# Lampung Fashion Tendance (LFT)

A high-performance, professional web application built for **Lampung Fashion Tendance**, the premier annual high-fashion showcase in Lampung, Indonesia. This platform is designed to bridge the gap between traditional ancestral craftsmanship and contemporary avant-garde design.

![Lampung Fashion Tendance Preview](https://lampungfashiontendance.com/favicon.ico) *Note: Replace with a real screenshot of your luxury UI*

## 💎 Project Essence

Lampung Fashion Tendance (LFT) is a prestigious movement spearheaded by **APPMI Lampung**. It serves as a definitive platform for preserving and evolving the rich textile heritage of the Lampung region, including:
- **Tapis**: Intricate gold-threaded weaves.
- **Sulam Usus**: Delicate and artistic embroidery.
- **Sulam Jelujur**: Traditional hand-stitching evolved into modern luxury.

## 🚀 Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Architecture**: Monorepo (using npm workspaces)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Ultra-Luxury Theme)
- **Animations**: Custom CSS Keyframes & Framer-style transitions
- **Integration**: WhatsApp Business API for direct enquiries

## ✨ Key Features

- **Luxury Split-Screen Hero**: A dramatic visual entry featuring high-fashion photography.
- **Glassmorphism Navigation**: A sophisticated, translucent header with smooth scroll behavior.
- **Collection Showcase**: A curated grid of masterpieces with direct "Private Enquiry" integration.
- **Responsive Excellence**: Fully optimized for a premium experience across mobile, tablet, and desktop.
- **Heritage Storytelling**: Dedicated sections explaining the legacy of Lampung Wastra.

## 🛠️ Getting Started

### Prerequisites
- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mfadlikurniawann-webdev/Lampung-Fashion-Tendance.git
   ```
2. Navigate to the project directory:
   ```bash
   cd lampungfashiontendance
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development
Run the development server:
```bash
npm run dev
```
The application will be available at `http://localhost:3000`.

### Building for Production
```bash
npm run build
npm start
```

## 🎨 Design Philosophy

The website follows an **"Ultra-Luxury"** aesthetic:
- **Colors**: Deep Black (`#0A0A0A`) base with Crimson Red (`#C53030`) accents.
- **Typography**: *Playfair Display* for editorial elegance and *Inter* for modern precision.
- **Imagery**: High-contrast fashion photography with smooth reveal animations.
